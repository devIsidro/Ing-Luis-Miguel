# J&H Electricidad y Plomería

Sitio web profesional desarrollado para **J&H Electricidad y Plomería**, empresa de servicios de electricidad y plomería ubicada en Villahermosa, Tabasco.

## Descripción

Este proyecto consiste en una landing page moderna orientada a la captación de clientes mediante WhatsApp. El sitio presenta los principales servicios de la empresa, galería de trabajos realizados, información de contacto y llamadas a la acción enfocadas en la generación de cotizaciones.

## Características

- Diseño responsivo para dispositivos móviles y escritorio.
- Integración directa con WhatsApp.
- Galería de trabajos realizados.
- Presentación de servicios de plomería y electricidad.
- Optimización para negocios locales.
- Navegación rápida y sencilla.

## Tecnologías utilizadas

- React
- CRACO
- JavaScript
- Tailwind CSS
- HTML5
- CSS3

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/devIsidro/Ing-Luis-Miguel.git
```

Instalar dependencias:

```bash
cd frontend
npm install
```

Iniciar entorno de desarrollo:

```bash
npm start
```

Generar versión de producción:

```bash
npm run build
```
